Why 1/5th (20%) Threshold?
  • Avoids Purge Loops: The common 50% rule for 'Free memory is lower than' threshold can cause games to enter an endless purge-and-recache loop, spiking CPU usage and causing micro-stutters.
  • Better Than Default: The default 1024 MB value is safe, but rarely triggers standbylist purging on modern 16GB/32GB RAM setups.
  • The Sweet Spot: 1/5th (20%) ensures standby RAM clears before disk-paging occurs without interrupting active game assets when RAM is required.

Tip: If you prefer a quick value to use without math, 2048 MB is a safe alternative.

Note: This explanation and formula are based on my personal understanding of how the ISLC standby list operates alongside default value. There is a possibility that my understanding is wrong.
